# M5 删除 Helper 部署说明

## 组件定位

`helper.exe` 是媒体节点上的可选管理员组件，只用于执行已经过中央删除流程确认、
并且位于本机允许目录内的删除请求。没有 Helper 时，Agent、Worker、扫描、同步
和相似分析仍可使用。

Helper 必须与 Agent 位于同一台 Windows 媒体节点，建议由同一部署账号运行。
本机控制管道只允许 SYSTEM、Administrators 和启动 Helper 的部署账号访问；换用
另一个管理员账号可能被拒绝。Agent 不会自动启动、停止或重启 Helper，Helper
是否启用和采用何种启动方式由节点托盘单独管理。

## 推荐的托盘部署流程

1. 管理员把 `helper.exe` 放入与本次节点发布相匹配的受保护固定程序目录；
2. 操作员启动 `nodetray.exe`，进入“删除 Helper”页签并明确启用组件；
3. 使用目录选择器或结构化列表添加 `allowed_roots`，点击“测试配置”；
4. 保持默认软删除，并把硬删除开关保持关闭；
5. 点击“授权并保存”，按需确认一次 UAC，让提升进程写入受保护配置；
6. 选择手动模式时点击管理员启动并确认 UAC；选择自动模式时由管理员安装固定
   的最高权限登录计划任务；
7. 返回“总览”确认 Helper 已认领、配置指纹匹配且删除服务管道就绪。

正常使用不直接编辑正式 JSON。旧节点迁移或开发诊断需要使用 CLI/JSON 时，
迁移完成后仍应由托盘重新加载、严格验证并保存。

## `allowed_roots` 安全规则

`allowed_roots` 不能为空，只能配置明确、窄范围、实际需要删除能力的本机媒体
目录。例如应选择具体媒体库子目录，而不是盘符根、Windows 目录、整个用户
目录、整个共享数据盘或其他项目的数据目录。

严禁把以下对象加入允许目录：

- 盘符根、系统目录、程序目录或配置目录；
- `$DedupRecycle` 等回收目录本身；
- 生成语料、输出目录或自动清理目标；
- 只读验收媒体目录，包括 `I:\tmp` 和 `H:\pik\00000000000`；
- 任何未获得所有者明确删除授权的目录。

Helper 仍会执行规范路径、拒绝根、重解析点和白名单边界检查；白名单不是绕过
用户选择、二次确认或审计的授权。

## 删除模式

- 新配置默认 `soft` 软删除；
- 建议把 `allow_hard_delete` 保持关闭；
- 软删除把文件移动到配置根内的受控回收目录，便于人工恢复；
- 硬删除不可恢复，只有确有需求、管理员明确开启且用户再次确认时才能执行；
- 加载既有硬删除配置时，托盘只显示高风险警告，不会静默改写；保存前必须再次
  确认。

## 手动模式与 UAC

手动模式下，操作员点击启动时 Windows 显示 UAC。取消 UAC 必须作为安全取消：
不启动 Helper，不修改正式配置，不创建任务，也不循环弹出。提升进程只执行本次
固定动作，完成后退出，不承载常驻界面。

## 自动模式与固定任务

自动模式不让 Agent 提权，也不接受任意计划任务参数。管理员通过一次性 UAC
安装项目定义的唯一固定、以最高权限运行的登录计划任务；任务只指向固定
`helper.exe` 和固定配置路径，并绑定同一部署账号。

每次使用前，托盘都要核对任务名、账号、最高权限标志、登录触发器、程序路径、
参数和工作目录。任何漂移都会被拒绝，并要求管理员明确修复。禁用 Helper 或
移除固定任务不会自动卸载程序、删除正式配置、日志或媒体文件。

## 配置和程序保护

保护 `helper.exe`、程序目录、正式 Helper 配置和 `.last-good` 备份，使普通用户
不能写入、替换、重命名或删除。管理员与 SYSTEM 按部署策略保留管理能力；部署
账号只取得运行和经控制面允许的读取权限。

保存由托盘的结构化表单发起，提升进程严格复验目标路径、程序身份、配置内容和
ACL，再执行原子替换。错误消息、通知和日志不得包含数据库连接、密码、确认值或
其他凭据。

## 停止、退出和故障

- Helper 停止优先通过独立本机控制管道请求受控关闭；
- 托盘最多等待 15 秒，超时后不自动强杀；
- 强制结束只能针对已认领 PID，并再次核对 PID、启动时间和规范程序路径；
- 退出托盘默认不停止 Helper；操作员必须明确选择“停止组件后退出”；
- Helper 异常退出只会使删除能力不可用，不影响 Agent 和 Worker 的媒体计算；
- Agent 不会因 Helper 退出而自动重启它。

## 不在范围

节点托盘不提供“删除节点”、Helper 卸载、程序文件删除、配置/日志清理、媒体
目录清理或远程 Helper 管理。需要卸载或迁移时，应由管理员按单独批准的部署
流程执行，并保留删除审计和必要备份。

更多固定路径、ACL、一次性提权和任务定义见
[节点托盘安全说明](node-tray-security.md)，完整日常操作见
[节点托盘部署与使用](node-tray.md)。真实 UAC、计划任务和 Helper 进程验收在未
授权运行前保持 `BLOCKED_NOT_RUN_DYNAMIC`。
