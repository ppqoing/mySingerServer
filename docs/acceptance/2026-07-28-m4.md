arguments. Even a preflight failure writes `m4-evidence.json`, marks every
unrun gate `NOT_RUN` with `null` exit code and empty log, redacts the DSN, emits
one line per required gate, prints one final FAIL line, and exits nonzero.

The controller defines exactly these 15 gates:


The E2E gate receives only the controller's freshly built evidence staging
directory through `M4_E2E_BIN_DIR`; it cannot silently use stale repository
binaries. The marker validator requires exact native JSON types, the expected
topology/status, E1–E4 facts, a safe run-owned evidence path, and exact PASS
evidence for every gate. Its negative matrices reject 380 marker/gate/log/path/
type mutations, 8 helper-contract mutations, and 7 bootstrap failures.
