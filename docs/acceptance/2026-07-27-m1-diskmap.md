## Independent Windows commands

```powershell
Get-Partition -DriveLetter C,D,F,G,H,I
Get-Partition -DiskNumber 1 -PartitionNumber 1 |
  Select-Object -ExpandProperty AccessPaths
Get-Disk
Get-PhysicalDisk
Get-CimInstance Win32_LogicalDisk
mountvol F:\ /L
```

`Get-Partition -DriveLetter` emits a non-terminating error for `F:` because
Windows does not assign that hidden EFI partition a Storage-cmdlet
`DriveLetter`. The independent `(disk 1, partition 1).AccessPaths` and
`mountvol F:\ /L` both return
`\\?\Volume{27899577-cb66-4647-8e9e-cb45e929e866}\`, exactly matching
the production diskmap Volume GUID. `Win32_LogicalDisk` independently shows
`F:` as a local FAT32 filesystem.
