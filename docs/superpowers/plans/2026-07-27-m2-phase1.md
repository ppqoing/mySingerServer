# M2 Phase 1 Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver `mediacore.dll`, an isolated `worker.exe` pool, image/video phase-1 feature computation, durable feature synchronization, and all M2 acceptance gates without regressing M1.

**Architecture:** Keep the existing root Go module and pure-Go `agent.exe`. Put all cgo and native decoding in a separate `worker.exe` linked to `mediacore.dll`; communicate over framed msgpack named pipes. Persist SHA-512 as lowercase hex text at Store/TCP boundaries while using 64-byte values internally, and preserve the v1.2 field-bit layout.

**Tech Stack:** Go 1.22+, C++17/MSVC 2022, CMake, vcpkg `x64-windows-static`, Windows CNG, libjpeg-turbo, libpng, libwebp, stb_image, Meta ThreatExchange PDQ, go-winio, SQLite, PostgreSQL 16, FFmpeg.

## Global Constraints

- Repository module is `dedup`; do not create an `agent/` submodule.
- `agent.exe` and `gui.exe` build with `CGO_ENABLED=0`; only `worker.exe` uses cgo.
- Configuration remains JSON and extends `internal/config/agent.go`.
- TCP/msgpack messages remain map encoded and backward compatible by adding fields only.
- SQLite/PostgreSQL/TCP SHA-512 remains 128-character lowercase hexadecimal `TEXT`; Worker/DLL SHA-512 is 64 raw bytes.
- Persistent/TCP bits remain: SHA `1<<0`, PDQ `1<<1`, thumbnail bundle `1<<2`, pHash `1<<3`, Sobel `1<<4`, video frames `1<<5`.
- Video duration and thumbnail are one persistent `FieldThumb` bundle. Partial writes preserve successful columns; the bundle bit clears only when duration, path, thumbnail PDQ, and quality all exist.
- PDQ BLOB byte order is official hex order (`w[15]` through `w[0]`, each word `%04hx`).
- PDQ source is pinned to `facebook/ThreatExchange` commit `baefb4ed67b6cdc1d4c82dbaef858d50866ac424`.
- Native dependencies use the installed vcpkg executable/ports snapshot `e0612b42ce44e55a0e630f2ee9d3c533a63d8bc1`; because this snapshot has no `.git` and GitHub:443 is unavailable, reproducibility evidence includes the vcpkg version and SHA-256 hashes of each declared port manifest/portfile instead of `builtin-baseline`.
- DLL uses `/fp:precise` or default precise floating point, never `/fp:fast`.
- Image resident-memory limit is 256 MiB; read chunk is 4 MiB.
- Worker handshake timeout is 10s; image watchdog 30s; video watchdog 120s; respawn delay 500ms.
- ffprobe timeout is 15s; ffmpeg screenshot timeout is 60s; thumbnail maximum side is 256px.
- IPC frame maximum is 16 MiB.
- Graceful pool shutdown sends `shutdown`, waits at most 3s, then kills residual workers; normal shutdown is not a crash and never respawns.
- All feature writes and their `sync_queue` generation update are in one SQLite transaction.
- No production code is written before its covering test has been run and observed failing for the expected missing behavior.
- This workspace has no Git repository. Replace commit steps with progress-ledger entries and a task-scoped independent review.

type MediaKind string
const (
    MediaImage MediaKind = "image"
    MediaVideo MediaKind = "video"

type Phase1Result struct {
    MachineID string
    Path string
    Kind MediaKind
    SHA512 []byte
    FieldsDone uint32

func (d *DB) SavePhase1(ctx context.Context, result Phase1Result) error
func (d *DB) MarkCrash(ctx context.Context, machineID, path, message string) error
