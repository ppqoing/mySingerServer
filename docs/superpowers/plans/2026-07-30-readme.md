# Root README Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建一份以普通用户快速启动为主、同时覆盖管理员部署和开发者构建的中文根目录 `README.md`。

**Architecture:** README 作为仓库入口，只描述经过源码和现有文档确认的运行链路：PostgreSQL 中心库、每台 Windows 媒体机器上的 Agent/Worker、中央 GUI Web，以及可选的提权删除 Helper。详细实现与验收不在 README 重复展开，而是通过相对链接指向现有文档。

**Tech Stack:** Markdown、Windows PowerShell、Go、CMake/MSVC、vcpkg、MinGW-w64、Docker Compose、PostgreSQL 16。

## Global Constraints

- 普通用户主路径必须先使用已有 `bin` 产物，再介绍源码构建。
- 支持平台明确为 Windows x64；不暗示 Linux 或 macOS 可运行。
- GUI HTTP 与 Agent TCP 没有 TLS 或业务鉴权，只描述可信局域网或回环部署。
- 不写入真实 PostgreSQL DSN、密码、令牌或机器专用凭据。
- Docker Compose 中的账号密码只标为开发示例，正式部署要求替换。
- Helper `allowed_roots` 必须使用用户明确选择的窄范围本地媒体目录。
- 不在 README 中出现受保护的真实媒体测试目录字面量。
- 删除流程必须说明“明确选择 → 确认 → 执行”，不提供自动删除或自动提权方案。
- M6 状态写为 `M6_COMPLETE_OWNER_ACCEPTED`，并链接最终验收边界。
- 当前工作区不是 Git 仓库；完成后报告文件修改和验证结果，不声称已提交。

- [ ] **Step 2: 写已有 `bin` 的快速启动**

按以下可执行顺序给出 PowerShell 命令：

```powershell
Set-Location D:\path\to\mySingerServer
if (-not (Test-Path bin\agent.json)) {
  Copy-Item deploy\agent.example.json bin\agent.json
}
if (-not (Test-Path bin\gui.json)) {
  Copy-Item deploy\gui.example.json bin\gui.json
}
if (-not (Test-Path bin\helper.json)) {
  Copy-Item deploy\helper.example.json bin\helper.json
}
docker compose -f deploy\docker-compose.yml up -d
```

说明如果 `bin\*.json` 已存在则先人工检查，不应直接覆盖。要求用户编辑：

- `agent.json`：唯一 `machine_id`、Agent `listen_addr`、可写 `data_dir`、
  实际 PostgreSQL DSN；
- `gui.json`：GUI `listen_addr`、相同 PostgreSQL DSN、所有 Agent 的
  `machine_id` 与 `addr`；
- `helper.json`：仅在需要删除功能时设置窄范围 `allowed_roots`。

启动命令必须使用程序实际支持的参数：

```powershell
Start-Process -Verb RunAs -FilePath (Resolve-Path '.\bin\helper.exe') `
  -ArgumentList '-config', 'helper.json' `
  -WorkingDirectory (Resolve-Path '.\bin')

.\bin\agent.exe -config .\bin\agent.json
.\bin\gui.exe -config .\bin\gui.json
```

说明 Helper 为可选；不使用删除功能时不启动。GUI 默认地址为
`http://127.0.0.1:8080/`。

日常操作说明包括：

多机部署说明：

- 每台机器运行自己的 Agent、Worker 和可选 Helper；
- 中央 GUI 的 `agents` 数组列出全部 Agent；
- Windows 防火墙只对可信局域网开放 Agent 端口；
- GUI 默认保持回环监听；如改为局域网地址，需要额外网络访问控制；
- 不直接向互联网暴露 GUI、Agent 或 PostgreSQL。

- [ ] **Step 1: 验证 README 结构和占位符**

运行 PowerShell 检查：

```powershell
$readme = Get-Content -Raw -LiteralPath README.md
$required = @(
  '# ', '## 快速开始', '## 日常使用', '## 多机部署',
  '## 配置说明', '## 从源码构建', '## 常见问题', '## 安全边界'
)
$missing = @($required | Where-Object { -not $readme.Contains($_) })
if ($missing.Count) { throw "README missing sections: $($missing -join ', ')" }
$placeholderTokens = @(('T' + 'BD'), ('FIX' + 'ME'))
foreach ($token in $placeholderTokens) {
  if ($readme -match "(?i)\b$([regex]::Escape($token))\b") {
    throw "README contains unresolved placeholder: $token"
  }
}
```
